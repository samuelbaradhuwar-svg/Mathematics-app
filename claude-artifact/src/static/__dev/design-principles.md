Thread: "Friendly notebook". A warm, calm maths notebook for a learner who has felt anxious about maths. Cream paper ground with a faint graph-paper grid used sparingly (hero areas, lesson canvas), ink-navy text, one confident indigo primary for the single obvious next action, and a sunshine-marigold accent for encouragement and progress highlights. Nothing shouts: mistakes are shown in soft coral (never alarm red), wins in leafy green.

Light and dark both supported (light is the default).

Pacing: generous. Large readable text (body about 18px on phones), big tap targets (min 48px), one idea per screen, lots of breathing room. Lesson steps are separate numbered cards with a coloured number badge so each tiny step is visually distinct.

Surfaces: rounded (16-24px) paper cards with a thin warm border and soft, low shadow; slight hand-made feel via the display face, not via clutter. Illustrations are simple SVG diagrams (number lines, fraction bars, balance scales, angle lines, grids) in the chart palette.

Type: Fredoka (rounded, friendly) for headings and buttons; Nunito (quiet, highly readable) for body; STIX Two Text for mathematical expressions so letters like x look like maths.

Status language is consistent everywhere: UNDERSTOOD = green, PRACTISING = indigo, NEEDS MORE HELP = marigold/coral, NOT STARTED = soft grey. Each status also has an icon and a word so colour is never the only signal.

Mobile first (iPhone): bottom tab bar with a raised Scan button, safe-area padding, no horizontal scrolling, one primary action per screen. Parent area is visually distinct (calmer slate palette, tighter density) so it never feels like Judah's space.
